# Go Paginators

A set of helpers for working with pagination using gormite.

## Functionality

* CursorPaginator - postgres
* FieldSortPaginator - postgres with sorting
* ElasticSearchPaginator - elasticsearch
* ElasticSearchSortPaginator - elasticsearch with sorting
